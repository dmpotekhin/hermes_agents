# 🐦 ブルーバード (Blue Bird) — учим песню с Gemini

> Опенинг №3 «Наруто: Ураганные хроники» (2008), группа いきものがかり (Икимоногакари).
> Слова и музыка: 水野良樹 (Мидзуно Ёсики).
> Уровень: N5+, в песне есть грамматика N4/N3 — Gemini объясняет её просто, на русском.
> Формат: как в основном плане — кандзи (хирагана ромадзи) — перевод, без акцента.

## 📌 Как пользоваться

1. Открой gemini.google.com (бесплатно, безлимит)
2. Скопируй **промпт** целиком (блок в конце файла) и отправь
3. Gemini разберёт песню по куплетам: чтение → перевод → слова → грамматика → караоке

## 🧠 Грамматика в песне (что будет объяснять Gemini)

| Конструкция | Значение | В песне |
|-------------|----------|---------|
| 〜たら | «когда/если сделаю» | 飛翔いたら, 突き抜けたら, 駆け出したら |
| 〜と言って | «сказав, что...» | 戻らないと言って |
| 〜のは | «то, что...» (номинализация) | 目指したのは |
| 〜ず | книжное отрицание «не...» | 覚えられず |
| 〜はじめた | «начал...» | つかみはじめた |
| 〜すぎる | «слишком...» | 眩しすぎた |
| 〜ほど | «чем... тем» | 振り切るほど, 求めるほど |
| 〜ていく | «продолжать/уходить вперёд» | 変わっていく, 捨てていく, 追い続けていく |
| 〜ても | «даже если...» | それでも |
