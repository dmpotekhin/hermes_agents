# Sound Feedback (Web Audio API)

Процедурные звуковые отклики в браузере без аудио-ассетов и без зависимостей — нативный
Web Audio API (осцилляторы + шум). Проверено на React 18 + Vite + TypeScript, но паттерн
универсален для любого JS-фронта.

## Когда использовать

- Нужны короткие звуковые отклики (клики, «динь», флип карты, таймер, раскрытие).
- Не хочется тащить mp3/ogg-файлы и лишние зависимости (Howler.js, Tone.js).
- Звук должен быть «сочнее» простого `beep()` — тогда уже смотреть Howler.js + ассеты.

## Ключевые паттерны

### 1. Ленивый AudioContext + autoplay-разблокировка
Браузер блокирует звук до первого жеста пользователя. Создавай контекст лениво
(`ensureCtx()`), а `resume()` вызывай и на первом `pointerdown`/`keydown`, и в самом
`play()` если `ctx.state === 'suspended'`. Иначе первый звук будет тихим.

### 2. Примитивы синтеза
- `tone(freq, start, dur, {type, gain, sweepTo})` — осциллятор + gain-огибающая.
- `noise(start, dur, {freq, q, gain})` — буфер белого шума через bandpass-фильтр.
Огибающие строятся через `exponentialRampToValueAtTime`. Готовый движок — в
`templates/sound.ts`.

### 3. Mute-состояние
Храни в `localStorage` (например `ao.muted`). Для React-реактивности используй
`useSyncExternalStore(subscribe, getSnapshot)` — подписка на изменение + snapshot
возвращает примитив. Реактивность без контекст-провайдера.

### 4. Мультиплеер: центральная маршрутизация socket-событий
Если приложение realtime (socket.io), сервер шлёт broadcast всем в комнате. Вешай
звуки ЦЕНТРАЛЬНО — один `SoundProvider` подписывается на события (`useSocketEvent`) и
вызывает `play(name)`, а не размазывай по страницам. Так звук слышат ВСЕ (включая
инициатора), и есть один источник истины «событие → звук».

## Верификация

- `tsc --noEmit` + `vite build`.
- Smoke-тест в браузере (playwright): тумблер mute переключается, `localStorage` пишется.
- Ошибки WebSocket/API в консоли от отсутствующего бэкенда — НЕ от аудио-кода, не чинить.

## Pitfalls

- `exponentialRampToValueAtTime` не принимает 0 — старт/финиш огибающей с 0.0001.
- `useSocketEvent` с инлайн-колбэком переподписывается на каждый рендер — ок для
  компонента без состояния, но держи колбэки стабильными (`useCallback`) если их много.
- Звук тихий до первого жеста — без unlock() первая попытка не проиграется.
