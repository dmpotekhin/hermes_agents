## Правила автотестов (TDD)
- Всегда RED → GREEN → REFACTOR: сначала тест (падает), потом минимальная реализация, потом чистка
- Один тест за раз, после каждого зелёного — маленький коммит
- Не коммитить секреты; не менять замороженные спецификации без спроса
- Имена тестов — по поведению, не по реализации
