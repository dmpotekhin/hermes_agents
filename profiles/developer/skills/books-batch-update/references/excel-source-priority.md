# Excel Source Priority

При обновлении `books-data.js` из `Книги.xlsx` нужно проверить, какой из двух файлов актуальнее:

| Источник | Путь |
|----------|------|
| Проектный (рабочий) | `~/Downloads/dmpotekhin.github.io/Книги.xlsx` |
| Downloads | `~/Downloads/Книги.xlsx` |

## Правило выбора
- Сравнить дату модификации (`ls -la`)
- Проектный обычно актуальнее (обновляется через сайт)
- Если в Downloads новее — скопировать поверх проектного перед пересборкой

## Сравнение содержимого
После копирования полезно проверить количество строк:

```python
import openpyxl
wb = openpyxl.load_workbook(PATH)
ws = wb.active
print(f"Rows: {ws.max_row}")
```
