## Copywriting Templates

### Landing Page Structure
1. Hero (заголовок + подзаголовок + CTA)
2. Problem agitation (боль/проблема ЦА)
3. Solution (как продукт решает проблему)
4. Social proof (отзывы, кейсы, цифры)
5. Features & benefits (характеристики → выгоды)
6. Pricing (тарифы, сравнение)
7. FAQ
8. Final CTA

### Email Sequence
- **Welcome (день 0):** Кто мы, что даём, первый полезный контент
- **Nurture (день 3):** Полезный контент, кейс, социальное доказательство
- **Offer (день 7):** Спецпредложение, ограничение по времени
- **Re-engagement (день 14):** «Скучаем», опрос, специальный бонус

### Social Media Post Formulas
- **Hook:** Вопрос / шокирующий факт / личная история / «Как я...»
- **Body:** Основная мысль + пример + детали
- **CTA:** Комментарий / репост / ссылка / вопрос к аудитории

## SEO Quick Checklist
1. Собрать семантику (keyword planner, competitors, autosuggest)
2. Кластеризовать запросы по интенту (информационные / транзакционные)
3. Проверить топ-10 конкурентов по каждому кластеру
4. Оценить контент-разрывы (что есть у конкурентов, чего нет у нас)
5. Составить контент-план с приоритетами
6. Для каждой страницы: Title, H1, meta description, структура H2-H3
7. Внутренняя перелинковка

## Analytics Metrics

| Метрика | Формула | Что измеряет |
|---------|---------|-------------|
| CTR | Клики / Показы | Эффективность заголовка/креатива |
| CR | Конверсии / Посетители | Эффективность страницы/воронки |
| CAC | Расходы / Новые клиенты | Стоимость привлечения |
| LTV | Средний чек × Срок жизни | Ценность клиента |
| ROAS | Доход / Расходы на рекламу | Окупаемость рекламы |

- Рассылка отзывов из таблицы
