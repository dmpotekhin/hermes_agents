# Hermes — инструкция для начинающих

## Что такое Hermes

Hermes — это твой личный помощник в компьютере. Ты пишешь ему сообщение —
он отвечает. Как чат в Telegram, только умнее: он может учить тебя
немецкому, писать тексты для работы, искать информацию и многое другое.

У тебя будет два помощника:
- **Фрау Вебер** — учитель немецкого (профиль `german-tutor`)
- **Маркетинг Про** — помощник по маркетингу и текстам (профиль `marketing`)

## Как открыть Hermes

1. Нажми клавишу **Windows** (с флажком) и набери `powershell`
2. Нажми Enter — откроется синее окно. Это терминал. Не бойся его!
3. Напиши `hermes` и нажми Enter

Через пару секунд появится приглашение — можно писать.

## Как переключаться между помощниками

Если хочешь учить немецкий:
```
hermes --profile german-tutor
```

Если хочешь работать с маркетингом:
```
hermes --profile marketing
```

Просто так (без профиля):
```
hermes
```

## Уроки немецкого с Фрау Вебер

Напиши в терминале:
```
hermes --profile german-tutor
```

Когда появится приглашение, напиши например:
- «Привет! Я хочу учить немецкий с нуля»
- «Повторим вчерашний урок»
- «Как сказать "Где вокзал?" по-немецки?»
- «Дай упражнение на артикли»

Фрау Вебер говорит с тобой по-немецки (с переводом новых слов на русский),
исправляет ошибки, даёт новые слова и упражнения.

## Маркетинг и тексты

Напиши:
```
hermes --profile marketing
```

Что можно попросить:
- «Напиши пост для Telegram про новую коллекцию»
- «Придумай 5 тем для рассылки на эту неделю»
- «Составь контент-план на месяц»
- «Проверь этот текст, что можно улучшить?»
- «Какой заголовок лучше для рекламы?»

Можно вставить готовый текст и попросить его улучшить.

## Основные правила

- **Пиши как человеку.** «Привет! Помоги мне с...» — не нужно специальных команд.
- **Уточняй если непонятно.** «Объясни проще», «Дай пример», «Повтори».
- **Не бойся ошибаться.** Если что-то не работает — просто напиши мне (Дмитрию).
- **Закрыть окно** — просто нажать крестик или написать `/exit`.

## Что делать если...

**«Не запускается»**
→ Закрой PowerShell и открой заново. Напиши `hermes`. Если ошибка — пришли мне скриншот.

**«Пишет какую-то ошибку»**
→ Не пугайся. Сфоткай экран и пришли мне. Почти всё чинится за минуту.

**«Забыла как переключить профиль»**
→ Закрой окно (крестик). Открой PowerShell заново. Напиши `hermes --profile german-tutor`.

**«Хочу продолжить вчерашний урок»**
→ Просто открой профиль и напиши «Продолжим с того места, где остановились».

## Где хранятся заметки

Hermes сохраняет историю всех разговоров. А ещё есть программа **Obsidian**
(иконка с фиолетовым кристаллом) — там будут сохраняться твои слова,
конспекты уроков и статистика времени.

## Коротко

| Что сделать | Что написать |
|-------------|-------------|
| Учить немецкий | `hermes --profile german-tutor` |
| Работа с текстами | `hermes --profile marketing` |
| Закрыть | `/exit` или крестик |
| Если сломалось | Пиши Диме 🙂 |
