## Источник данных (KanjiVG)

- **Проект:** https://github.com/KanjiVG/kanjivg (CC BY-SA 3.0 Ulrich Apel)
- **SVG на GitHub raw:** `https://raw.githubusercontent.com/KanjiVG/kanjivg/master/kanji/{codepoint}.svg`
- **Формат кодпоинта:** 5 hex-цифр с ведущим нулём (padStart(5, '0')). Пример: 一 (U+4E00) → `04e00.svg`, 大 (U+5927) → `05927.svg`
- **SVG-структура:** `<path id="kvg:XXXXX-sN"` — каждая черта с номером N. Сортировать по суффиксу `-sN`.
- **Покрытие:** ~13,000 SVG (все Jōyō + Jinmeiyō + дополнительные)

## Возможности

- Ввод любого кандзи → показ по чертам
- Навигация ◀ ▶, клавиши ← →, пробел
- Авто-проигрывание с регулируемой скоростью
- Dots-бар: 🔴 пройденные, 🟡 текущая glow, ⚫ будущие
