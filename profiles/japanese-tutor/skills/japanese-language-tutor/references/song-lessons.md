# Уроки по песням (Song Lessons) — промпты для Gemini

Класс задачи: пользователь просит «напиши промпт для Gemini, чтобы выучить песню X».
Формат наследует pokemon_conversation_plan.md, но по одной песне.
Рабочий пример: `~/.hermes/jp_rag_data/bluebird_song_prompt.md` (ブルーバード, опенинг Наруто, いきものがかり, создан 2026-08-12).

## Структура файла <song>_song_prompt.md

1. Шапка: исполнитель, откуда песня (аниме/опенинг/дорама), уровень ученика, формат
2. 📌 Как пользоваться (открыть gemini.google.com, скопировать промпт)
3. 📜 Полный текст песни по куплетам — таблица 4 колонки: Кандзи | Хирагана | Ромадзи | Перевод
4. 📚 Ключевые слова — 4 колонки (15-30 слов)
5. 🧠 Грамматика из песни — таблица: Конструкция | Значение | Пример из песни
6. 🤖 Промпт для Gemini (самодостаточный, code block)

## ⚠️ Критично: хирагана + ромадзи в КАЖДОЙ строке песни

Коррекция пользователя 2026-08-12 (Blue Bird): «нужно добавить чтение хироганой и ромадзи».

- НЕЛЬЗЯ строки вида «кандзи — перевод» без чтения — пользователь поправил именно это.
- Формат строки в промпте:
  `飛翔いたら 戻らないと言って (はばたいたら もどらないといって / habataitara modoranai to itte) — когда расправлю крылья, сказав: «не вернусь»`
- Таблицы текста песни: 4 колонки с ромадзи. Вариант «Строка | Чтение | Перевод», где чтение только хираганой, — не подходит.
- Правило №2 в самом промпте для Gemini тоже должно требовать этот формат вывода (кандзи (хирагана ромадзи) — перевод, строка целиком).

## Где взять текст песни (проверено 2026-08-12)

Проверенный источник: **j-lyric.net** — доступен через curl с браузерным User-Agent, текст лежит в `<div id="Lyric">`, фуригана прямо в тексте (飛翔(はばた)いたら).

Workflow:
1. `web_search("site:j-lyric.net <исполнитель> <название>")` — найти точный URL. У j-lyric URL содержит коды артиста/песни (например, artist/a04c814/l00df96.html), угадать нельзя — искать обязательно.
2. `curl -sL -A "Mozilla/5.0 ... Chrome/120.0" "<url>" -o /tmp/song.html`
3. Парсинг: `<div id="Lyric">`, `<br>` → `\n`, strip tags, html.unescape.
4. ⚠️ Проверять `<title>` страницы — при неверном URL j-lyric может отдать другую песню (реальный случай: по догадке попали на タッキー&翼 вместо いきものがかり).

Если uta-net (Cloudflare «Just a moment...») или Genius (web_extract «private network address») недоступны — не тратить попытки, сразу искать j-lyric.

## Атэдзи в тексте

В песнях встречаются кандзи с нестандартным чтением:
- 遊迷(ゆめ) — «мечта» (игра слов: странствие+мечта), авторская
- 共鳴(あず)けて = 預けて «вверив» — атэдзи
Помечать такие места блоком 💡 в файле, чтобы Gemini и ученик не путались.

## Извлечение лексики в user_vocab.json

После промпта пользователь часто просит «добавь слова» → стандартный bulk-add скрипт (write_file → python3 → rm), dedup по hiragana.

- Темы: глаголы, прилагательные, природа, здоровье, вещи; для эмоций (悲しみ, 切なさ, 感情) — новая тема «чувства» (добавлять в info.themes + в references/user-vocab-database.md).
- После добавления: обновить README (3 места: дерево, таблица описания, таблица Anki), references/user-vocab-database.md (JSON-блок + тематические группы), git add только нужных файлов.
- Проверять на дубликаты и по hiragana, и по kanji (戻る уже был в базе — пропущен).

### ⚠️ Верификация: скоуп полноты полей только на новые слова

При проверке user_vocab.json НЕ проверять обязательность полей по всей базе — старые кана-слова из Pokemon (あっ, オレ, きみ, まて) легально имеют пустые kanji/romaji (чисто кана-слова, без кандзи/ромадзи). Это пре-существующее состояние базы, не ошибка.

- По всей базе проверять: total_words == len(words), нет дубликатов hiragana, id непрерывны 1..N, themes корректны.
- Полноту полей (kanji, hiragana, romaji, translation, theme, date_added) проверять ТОЛЬКО для вновь добавленных записей.
- Реальный случай 2026-08-12: первый прогон проверки дал ложный FAIL по ~60 старым Pokemon-словам; перепроверка со скоупом на 19 новых слов — PASS.
