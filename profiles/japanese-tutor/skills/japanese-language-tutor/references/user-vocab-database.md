# Персональный словарь пользователя (из разговорного клуба)

## Расположение

`~/Downloads/jp_rag_data/user_vocab.json`

## Структура файла

```json
{
  "info": {
    "description": "Персональный словарь из разговорного клуба японского языка",
    "created": "2026-06-20",
    "last_updated": "2026-06-22",
    "total_words": 131,
    "themes": ["знакомство", "вопросы", "местоимения", "приветствия",
               "страны", "частицы", "вежливость", "профессии",
               "языки", "хобби", "еда", "утверждения",
               "семья", "счёт людей", "глаголы"]
  },
  "words": [...]
}
```

### Поля записи

| Поле | Обязательно | Описание |
|------|-------------|----------|
| id | да | автоинкремент |
| kanji | да | кандзи или катакана/хирагана |
| hiragana | да | чтение |
| romaji | да | латиница |
| translation | да | перевод на русский |
| theme | да | категория для группировки |
| date_added | да | дата добавления |
| note | нет | грамматический нюанс, контекст, правило |

### info секция — поддерживать в актуальном состоянии

- `total_words` — обновлять при каждом добавлении
- `themes` — пополнять при появлении новой темы
- `last_updated` — дата последнего изменения

## Workflow получения слов от пользователя

### Форматы ввода

**1. Список слов (структурированный):**
```
出来ます (Dekimasu) — Уметь, мочь
日本語 (Nihongo) — Японский язык
```
→ kanji + romaji + translation даны. Хирагану можно найти или поставить.

**2. Список слов в 4-столбцовом формате:**
```
夫 (おっと、otto) - муж
妻 (つま、tsuma) - жена
```
→ kanji + hiragana + romaji + translation в одной строке. Самый полный формат.

**3. Диалог с грамматическими комментариями:**
```
A: 鈴木さん、お国は？ (Suzuki-san, okuni wa?)
B: 日本です。 (Nihon desu。)

***
Комментарий:
お国 (okuni) — страна (вежл.)
```
→ Слова извлекать из диалога. Комментарии — отличный источник nuance.
→ Разговорные фразы (お国は？, お名前は？) — сокращённые варианты.

**4. Голый список слов (как в задании):**
```
料理 (Ryōri) - Приготовление еды
写真 (Shashin) - Фотография
```
→ Всё как есть.

**5. Комбинированный ввод (word list → dialog) — новый паттерн:**
Сначала пользователь присылает список новых слов (например, родственников),
затем — полный диалог из разговорного клуба, в котором эти слова используются.
Слова уже добавлены на первом шаге, диалог подтверждает контекст.
→ На втором шаге добавлять только НОВЫЕ слова из диалога (счётные суффиксы,
частицы, глаголы), не дублировать уже добавленные.

**6. Серия диалогов одной темы — новый паттерн:**
После первого диалога (о количестве человек в семье) → второй диалог
(о том, есть ли братья/сёстры, где живут). Второй диалог раскрывает тему глубже
и добавляет:
- Вежливые формы родственников (для чужих)
- Глагол 住む + конструкция に住んでいます
- Частицу に (места)
→ Обрабатывать последовательно: сначала слова из диалога 1, потом из диалога 2.
→ Перед добавлением сверять с user_vocab.json — вежливые формы НЕ дублируют
простые формы (父 ≠ お父さん), это разные записи.

### Правила разбора

1. **Сверять с уже имеющимися в user_vocab.json** — не дублировать
2. **Притяжательные/вопросительные фразы** (お国, お名前, お仕事) — добавлять отдельно с пометкой theme=вежливость
3. **Грамматические частицы** (か, よ, の, と, に) — добавлять если пользователь выделил их в комментариях
4. **Стандартные фразы-клише** (宜しくお願いします, 初めまして, そうですか) — добавлять как целые записи
5. **Имена собственные** (鈴木, イリナ) — НЕ добавлять
6. **Формы глаголов** (出来ます → 出来ません) — добавлять обе, связывать через note
7. **Варианты чтения** (何 = なん/なに) — указывать через /
8. **Варианты одной фразы** (どうぞよろしく vs よろしく) — добавлять как отдельные записи
9. **Счётные суффиксы** (一人, 二人, 三人...) — добавлять все варианты от 1 до 10, исключения (一人=hitori, 二人=futari) помечать в note
10. **Вежливые формы родственников** (お父さん, お母さん, お兄さん...) — добавлять отдельными записями с theme=вежливость, в note указывать соответствие простой форме (父→お父さん)
11. **Глаголы** (住む, 出来ます) — добавлять в theme=глаголы в словарной форме, в note указывать употребительную форму (住んでいます)

### Подача результата пользователю

После добавления:
1. Показать таблицу новых слов (kanji | hiragana | romaji | translation) — компактно
2. Выделить 1-2 грамматических/культурных нюанса
3. Если накопилось много — предложить квиз
4. Сказать общее количество слов в базе
5. Если слова добавлены из нескольких источников (список + диалог 1 + диалог 2) — сгруппировать по темам, показать отдельно

### Контекстные подсказки

- **любить/не любить**: 好きです / 好きじゃないです — частица が маркирует объект
- **мочь/не мочь**: 出来ます / 出来ません — тоже が
- **вопросительное か**: в конце предложения
- **よ**: частица уверенности («ведь», «же»)
- **お-префикс**: вежливость, только о собеседнике, не о себе
- **読書**: dokusho, не doku sho — одно слово
- **языки**: [страна без こく] + 語 (ご), кроме 英語 (eigo)
- **счёт людей**: 一人 (hitori), 二人 (futari) — исключения, далее регулярно: さんにん, よにん...
- **свои vs чужие родственники**: 父/お父さん, 母/お母さん, 兄/お兄さん, 姉/お姉さん, 弟/弟さん, 妹/妹さん
- **います vs あります**: います для одушевлённых (люди, животные), あります для неодушевлённых (вещи)
- **と (to)**: совместный падеж, соединяет существительные («и», «с»)
- **に住んでいます**: конструкция «жить в (месте)», に — частица места

## Типичные паттерны диалогов в клубе

Каждый урок строится по схеме:
1. Диалог A/B (4-6 реплик)
2. Комментарии (грамматические пояснения)
3. Задания (прочитать, разыграть, записать)
4. Список тематических слов

Темы идут последовательно: знакомство → страны → профессии → языки → хобби → еда → семья.

## Cross-Reference: JLPT Patterns → User Vocab

Когда пользователь просит сверить JLPT-слова с разговорным клубом:

### Практический код сверки

```python
import json

# 1. Загрузить patterns.jsonl
patterns = {}
with open('~/Downloads/jp_rag_data/patterns.jsonl') as f:
    for line in f:
        p = json.loads(line)
        patterns[p['id']] = p

# 2. Загрузить user_vocab.json
with open('~/Downloads/jp_rag_data/user_vocab.json') as f:
    user_vocab = json.load(f)

existing = set()
for w in user_vocab['words']:
    existing.add(w['kanji'])
    existing.add(w['hiragana'])

# 3. Сверить по pattern ID из study_plan.json
plan = json.load(open('~/Downloads/jp_rag_data/study_plan.json'))
pids = []
for day in plan['days'][:5]:  # можно ограничить N дней
    pids.extend(day['patterns'])

missing = []
for pid in pids:
    p = patterns.get(pid)
    if not p:
        continue
    for v in p.get('vocabulary', []):
        if v['word'] not in existing and v['reading'].split('(')[0] not in existing:
            missing.append((v['word'], v['reading'], v['meaning'], pid))
```

### Важные нюансы при сверке

1. **Чтение в patterns.jsonl** содержит ромадзи в скобках: `わたし(watashi)` — экстрагировать только хирагану
2. **Многие паттерны не имеют vocab-секции** — это нормально (чисто грамматические паттерны)
3. **Сравнивать и по kanji, и по hiragana** — некоторые слова записаны катаканой
4. **Добавленные слова** помечать note: `"из JLPT N5 — День N"`
