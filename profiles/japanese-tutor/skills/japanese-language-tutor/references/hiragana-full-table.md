# Полная таблица хираганы (ひらがな)

## Гласные (5)

| Символ | Чтение | Мнемоника |
|--------|--------|-----------|
| あ | a | Похожа на букву «а» с перекладиной |
| い | i | Два штриха, как два «и» |
| う | u | Хвостик «у» вверх |
| え | e | Как буква «N» с чёрточкой |
| お | o | Буква «o» с закорючкой |

## K-ряд (5)

| Символ | Чтение | Мнемоника |
|--------|--------|-----------|
| か | ka | «K» + あ = か |
| き | ki | Похожа на ключ (key) |
| く | ku | Похожа на клюв курицы |
| け | ke | Похожа на кеглю |
| こ | ko | Как два корабля навстречу |

## S-ряд (5)

| Символ | Чтение | Мнемоника |
|--------|--------|-----------|
| さ | sa | Похожа на саблю |
| し | shi | Похожа на шило |
| す | su | Похожа на суп (струя пара) |
| せ | se | Похожа на букву «с» |
| そ | so | Похожа на согнутую букву «с» |

## T-ряд (5)

## Сдвоенные согласные

Маленький っ удваивает следующую согласную:
- かった (katta) — выиграл
- きって (kitte) — марка
- にっぽん (nippon) — Япония

## Долгие гласные

- あ + あ = aa (долгая а)
- い + い = ii (долгая и)
- う + う = uu (долгая у)
- え + い = ee (долгая э)
- お + う = oo (долгая о)
- お + お = oo (долгая о, реже)

## Простые слова для практики по рядам

### После гласных + K
- いえ (ie) — дом
- うえ (ue) — верх
- あお (ao) — синий
- かお (kao) — лицо
- きく (kiku) — хризантема
- あき (aki) — осень
- いか (ika) — кальмар
- くい (kui) — колышек

### После S
- すし (sushi) — суши
- あさ (asa) — утро
- いす (isu) — стул
- かさ (kasa) — зонт
- せき (seki) — место/кашель
- そと (soto) — снаружи

### После T
- ちち (chichi) — отец
- て (te) — рука
- つき (tsuki) — луна
- たつ (tatsu) — стоять/дракон
- きた (kita) — север
- とし (toshi) — год/город

### После N
- なな (nana) — семь
- にほん (nihon) — Япония
- ねこ (neko) — кошка
- いぬ (inu) — собака
- はな (hana) — цветок/нос
- ふね (fune) — корабль

### После H + M
- はは (haha) — мать
- ひ (hi) — огонь/день
- ふく (fuku) — одежда
- へた (heta) — неумение
- ほし (hoshi) — звезда
- まち (machi) — город
- みみ (mimi) — ухо
- むし (mushi) — насекомое
- め (me) — глаз
- もも (momo) — персик

### После Y + R + W
- やま (yama) — гора
- ゆき (yuki) — снег
- よる (yoru) — ночь
- はる (haru) — весна
- ふる (furu) — старый/идти (о дожде)
- そら (sora) — небо
- かわ (kawa) — река
- わたし (watashi) — я
