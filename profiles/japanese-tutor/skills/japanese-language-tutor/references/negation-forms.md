# Отрицание существительных — 4 формы

Русскоговорящие ученики часто видят разные формы отрицания в Duolingo, учебниках и JLPT. Вот полный разбор.

## Общая схема

```
Утверждение:  学生 です  (gakusei desu)
Отрицание:    学生 じゃないです / じゃありません / ではありません
```

## Формы по степени вежливости

| № | Форма | Пример | Уровень | Где используется |
|:-:|:-----:|:------:|:-------:|:----------------|
| 1 | **ではありません** | 学生ではありません | 👔 Официально | JLPT экзамен, деловая переписка, с незнакомыми |
| 2 | **じゃありません** | 学生じゃありません | 😊 Вежливо | Повседневная вежливая речь, с коллегами |
| 3 | **じゃないです** | 学生じゃないです | 🤝 Казуально-вежливо | Duolingo, разговорная речь, с друзьями + です |
| 4 | **じゃない** | 学生じゃない | 🍺 Казуально | Только с близкими друзьями, без です |

## Анатомия

**じゃないです** = では(wa) + ない(nai, отрицание) + です(вежливость)

- では → じゃ (разговорное сокращение)
- ない — отрицательная форма (как «не»)
- です — добавляет вежливость

## Примеры всех 4 форм для одного предложения

| Форма | Предложение |
|:-----:|:-----------|
| ✅ | 私は医者**です**。 (утверждение) |
| 👔 | 私は医者**ではありません**。 |
| 😊 | 私は医者**じゃありません**。 |
| 🤝 | 私は医者**じゃないです**。 |
| 🍺 | 私は医者**じゃない**。 |

## Когда какую использовать

| Ситуация | Форма |
|---------|:-----:|
| JLPT N5 экзамен | ではありません |
| Письмо начальнику | ではありません |
| Разговор с коллегой | じゃありません / じゃないです |
| Duolingo обучение | じゃないです |
| С друзьями в баре | じゃない |
| Вежливый разговор с незнакомцем | じゃないです или じゃありません |

## Связь с глагольным отрицанием

Та же логика работает и для глаголов:
- ます → ません (вежливое отрицание: 行き**ます** → 行き**ません**)
- ない (казуальное: 行く → 行か**ない**)

## Формула для запоминания

```
Существительное + ではありません (самый формальный, никогда не ошибешься)
Существительное + じゃないです  (самый универсальный в речи)
Существительное + じゃない     (только для друзей)
```
