# ⚠️ Anki → user_vocab.json: обратное извлечение лексики

## Проблема

Anki-колода `N5_vocab_days.apkg` (1444 карточки) **не пригодна для прямого импорта**
в `user_vocab.json`. ~35% карточек — шум: фрагменты предложений, спряжённые
глаголы, имена собственные.

## Почему так получилось

Скрипт `build_n5_anki.py` извлекает лексику из **примеров предложений**
patterns.jsonl, разбивая `hiragana_examples` по пробелам и отфильтровывая
только SKIP-слова (частицы, связки, местоимения).

**Проблема:** фильтр пропускает частицы / だ / です / ます / た **только
как отдельные токены**. Если частица «прилипла» к слову в hiragana_examples
(что часто бывает в данных Akuzawa — `かのじょの`, `しゅっしんちは`), она
проходит фильтр как часть слова.

**Результат в Anki:**

| Kanji | Hiragana | Реальность |
|-------|----------|------------|
| 彼女 | かのじょの | «её» — слово + частица の |
| 出身地 | しゅっしんちは | «родной город + は» |
| 看護師 | かのじょは | «она + は» (kanji не совпадает!) |
| 教室 | おとこのこ | kanji=教室, reading=«мальчик» — ошибочное сопоставление |
| (无) | さくばんわたしははやくねた | целое предложение как слово |

## Категоризация шума

| Категория | Как выглядит | Пример | ~% в колоде |
|-----------|-------------|--------|------------|
| **Фрагмент + частица** | Оканчивается на は/が/を/に/で/へ/の | かのじょの, しゅっしんちは | ~30% |
| **Фрагмент + だ/です/ます** | Оканчивается на связку | ありぞなです, おおさかだ | ~5% |
| **Спряжённый глагол** | Форма た/て/ます/ない | かえった, もった, かいた | ~5% |
| **Целое предложение** | 10+ символов, несколько слов | さくばんわたしははやくねた | ~2% |
| **Ошибочное kanji** | Kanji не соответствует чтению | 教室→おとこのこ, 午前→なんじ | ~5% |
| **Имя собственное** | たなかさん, すずきさん | Имена | ~3% |

**Чистых слов с переводом:** ~10-15 из 1444.

## Скрипт фильтрации

Использовать `scripts/extract_anki_vocab.py`:

```bash
python3 scripts/extract_anki_vocab.py path/to/deck.apkg --vocab user_vocab.json
```

Скрипт классифицирует каждую карточку:
- **exists** — уже в user_vocab.json
- **clean** — кандидат на добавление (есть kanji, нет частиц-хвостов)
- **fragment** — фрагмент с частицей/связкой (пропустить)
- **conjugated** — спряжённая форма глагола (пропустить)
- **katakana_only** — только катакана без перевода (пропустить)
- **too_short** — 1 символ (пропустить)

## Алгоритм фильтрации (если правишь вручную)

```
1. Отбросить всё, что оканчивается на частицу (はがをにでへとのもや)
2. Отбросить всё, что оканчивается на だ/です/ます/でした/ません
3. Отбросить глаголы не в словарной форме (ます/た/て/ない/たい)
4. Проверить, что кандзи в слове соответствует чтению
5. Отбросить имена собственные (фамилии на さん/くん/ちゃん)
6. Оставшееся — проверить по user_vocab.json (дедупликация по hiragana)
```

## Когда НЕ нужно извлекать из Anki

- Если слова уже были добавлены через bulk reconciliation (curated N5 list)
- Если цель — изучение через Anki (фрагменты нормальны для карточек, но не
  для словаря)
- Если слова уже есть в patterns.jsonl `vocabulary`-поле

## Когда извлекать нужно

- Пользователь явно запросил «добавь мне все слова из Anki в словарь»
- В колоде появились новые curated-слова (не из примеров)
- При сверке двух версий колоды
